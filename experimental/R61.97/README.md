# YOMI v4.2.0.8 R61.97 — Experimental Beta

R61.97 is the current experimental Windows beta of YOMI.

## Install

1. Download the **`experimental-r61.97` branch** as a ZIP from GitHub.
2. Fully extract the ZIP.
3. Double-click **`INSTALL EXPERIMENTAL R61.97.cmd`**.
4. Approve the normal Windows administrator prompt.

The beta can be installed on a clean machine or over YOMI v4.2.0.7 or a supported earlier 4.2.0.8 beta. Existing YOMI user data in **`%LOCALAPPDATA%\YOMI`** is preserved.

## What's changed in R61.97

- More compact controller layout with less wasted space.
- Better live resizing and small-window behavior.
- Cleaner one-row Queue controls and a denser table layout.
- Larger, sharper visualizer presentation.
- Improved artwork edge and crop handling.
- Continued fixes for media presentation, playback transitions, and responsiveness.

## Testing

R61.97 is experimental. If something breaks, open a GitHub Issue with a concise description and attach the YOMI diagnostic / Flight Recorder bundle when the problem involves playback, media, OBS, or responsiveness.
