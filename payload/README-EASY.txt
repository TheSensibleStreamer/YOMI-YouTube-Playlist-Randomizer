YOMI 420.69.9004 — YouTube OBS Music Interface

INSTALL
1. Fully extract this ZIP.
2. Double-click INSTALL YOMI.cmd.
3. Open YOMI, add your YouTube playlist, and press Listen.

OBS (optional)
Open YOMI Settings > OBS, then use Quick Setup. Copy the shown Browser Source URL and size into OBS.

UPDATES
YOMI checks for updates automatically. You can also use Help > Check for updates.

UNINSTALL
Use the YOMI Start Menu shortcut or Uninstall YOMI.cmd.
